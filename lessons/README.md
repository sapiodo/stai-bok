# Lessons

Лекционные конспекты курса 12-CM-STAI (Systems Thinking with AI). Адаптация — академический запуск 514-CM-MIPT (МФТИ, 3-й курс).

Линейный путь — последовательно от L1 к L7. Если у тебя другой путь (problem-driven или concept-driven) — конспекты остаются справочным материалом, обращайся к ним выборочно.

## Использование с skills

Каждый конспект ссылается на концепты в `concepts/`. После прочтения конспекта:

- **Глубже разобрать концепт?** → `/study-concept <slug>`
- **Применить на своём кейсе?** → `/solve-problem`
- **Самопроверка?** → `self-tests/Q<N>-*.md`

## Источник

Конспекты — отредактированные тексты с очных занятий курса 514-CM-MIPT (МФТИ, 2026). Они сохраняют разговорный тон и логику последовательности занятий, в отличие от структурированных концепт-карточек.

При расхождении между конспектом и концепт-карточкой — приоритет у карточки (`concepts/`).
