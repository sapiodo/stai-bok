# Phase 3: Решение

**Цель фазы:** от системного диагноза к портфелю гипотез. Поиск точек рычага на 5 уровнях Медоуз, анализ стейкхолдеров, приоритизация Effort/Impact.

**Концепты для опоры:** `concepts/08-leverage-points.md`, `concepts/09-stakeholder-map.md`, `concepts/10-effort-impact.md`, `concepts/11-hypothesis-portfolio.md`.

---

## Принципы фазы

- **Парадокс рычага:** чем сильнее уровень — тем сложнее использовать. Параметры — за день, парадигмы — за годы.
- **Предупреждение Медоуз:** люди интуитивно находят правильную точку рычага, но толкают её в **неправильном направлении**. Знать *где* — половина дела.
- Минимум **1 гипотеза уровня 3+** в портфеле. Иначе работаем только на параметрах.

---

## Шаги

### Шаг 3.1. Уровни рычага Медоуз

Для каждой найденной точки воздействия определи уровень (1-5):

| # | Уровень | Что это | Пример | Сила | Сложность |
|---|---|---|---|---|---|
| 1 | **Параметры** | Числа, бюджеты, константы | Бюджет маркетинга +10% | ⚪ Слабый | Низкая |
| 2 | **Буферы (Stocks)** | Запасы прочности, накопления | Снизить техдолг, накопить экспертизу | ⚪ Слабый+ | Низкая-средняя |
| 3 | **Структура** | Правила, инфо-потоки, самоорганизация | Сделать метрики retention публичными | 🔵 Средний | Средняя |
| 4 | **Цели системы** | К чему стремится система | KPI «количество фичей» → «impact на retention» | 🟠 Сильный | Высокая |
| 5 | **Парадигмы** | Ментальные модели, убеждения | «Пользователи = трафик» → «Пользователи = сообщество» | 🔴 Очень сильный | Очень высокая |

**Связь с Iceberg:**

| Уровень Iceberg | Типичный уровень рычага |
|---|---|
| События | 1 — параметры (слабый) |
| Паттерны | 2 — буферы / 3 — структура (средний) |
| Структуры | 3 — структура (средне-сильный) |
| Ментальные модели | 4 — цели / 5 — парадигмы (сильный) |

### Шаг 3.2. Карта стейкхолдеров

Точки рычага не существуют в вакууме. Карта помогает предвидеть: кто поддержит, кто заблокирует.

```
                Высокое влияние
                      │
 Держать довольными   │   Управлять тесно
 (информировать)      │   (вовлекать, согласовывать)
                      │
Низкий ───────────────┼─────────────── Высокий
интерес               │                интерес
                      │
 Мониторить           │   Держать в курсе
 (минимум усилий)     │   (собирать фидбек)
                      │
                Низкое влияние
```

| Квадрант | Стратегия |
|---|---|
| Высокое влияние + высокий интерес | **Управлять тесно** — совместные решения |
| Высокое влияние + низкий интерес | **Держать довольными** — не создавать проблем |
| Низкое влияние + высокий интерес | **Держать в курсе** — обновления, фидбек |
| Низкое влияние + низкий интерес | **Мониторить** — отслеживать изменение позиции |

### Шаг 3.3. Приоритизация — Effort / Impact

```
                Высокий Impact
                      │
 Стратегические       │   Quick Wins
 проекты              │   (делать первыми!)
 (планировать)        │
                      │
Высокий ──────────────┼─────────────── Низкий
Effort                │                Effort
                      │
 Отложить /           │   Fill-ins
 пересмотреть         │   (если есть время)
                      │
                Низкий Impact
```

- **Effort** = организационная сложность (ресурсы + техсложность + согласования + время)
- **Impact** = ожидаемый эффект на проблему. Выше уровень рычага → выше потенциальный impact.

### Шаг 3.4. Формирование портфеля

Для каждой гипотезы:

| Поле | Описание |
|---|---|
| **Название** | 1-3 слова |
| **Действие** | 1 предложение: что конкретно делаем |
| **Уровень рычага** | 1-5 по Медоуз |
| **Effort** | Высокий / Средний / Низкий |
| **Impact** | Высокий / Средний / Низкий |

**Правила портфеля:**
- **Quick Wins** (уровни 1-2) — для быстрого результата и мотивации
- **Стратегические проекты** (уровни 3-5) — для долгосрочных изменений
- **Минимум 1 гипотеза уровня 3+**
- Оптимум: **3-5 гипотез**

**При двух треках (см. SKILL.md):** отдельный портфель для трека A (коррекция) и трека B (редизайн).

## Антипаттерны фазы

- ❌ Все гипотезы на уровне 1-2 (работаем на параметрах, парадигма не двигается)
- ❌ Все гипотезы на уровне 4-5 (нет Quick Wins → команда теряет мотивацию через месяц)
- ❌ Игнорировать стейкхолдеров уровня «Высокое влияние + низкий интерес» (они могут заблокировать)
- ❌ Effort/Impact «на глаз» без обоснования
- ❌ Толкать правильную точку рычага в неправильном направлении (предупреждение Медоуз)
