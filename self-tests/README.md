# Self-Tests

Квизы для самопроверки усвоения концептов BoK. Каждый квиз — 10 вопросов в задачном формате (на применение, не на воспроизведение определений).

| Квиз | Концепты | Урок |
|---|---|---|
| `Q2-problem-formulation.md` | `problem-formulation`, `cynefin`, `five-whys` | L2 |
| `Q3-iceberg-cld.md` | `iceberg-model`, `causal-loop-diagrams` | L3 |
| `Q4-iceberg-cld-v2.md` | `iceberg-model`, `causal-loop-diagrams` | L3 (расширенная версия) |
| `Q5-system-archetypes.md` | `system-archetypes` | L4 |
| `Q6-leverage-points-apply.md` | `leverage-points`, `stakeholder-map`, `effort-impact` | L5 |
| `Q7-leverage-points-mini.md` | `leverage-points`, `hypothesis-portfolio` | L5 (мини) |

## Формат ответов

Правильные ответы в квизах **выделены жирным**. Это сделано для удобства самопроверки.

**Рекомендация:** перед прохождением закрой ответы (например, в редакторе скопируй текст квиза без жирного маркера в отдельный файл) и проверь себя честно. Затем сверься с оригиналом.

## Прохождение

- Проходной балл: ≥ 70% правильных ответов
- Время на квиз: ~10-15 минут
- Если результат ниже порога — пройди соответствующие концепт-карточки через `/study-concept <slug>` в режиме `deep-study`

## Дополнительно

В реальном курсе 514-CM-MIPT квизы сопровождались разбором ошибок на занятии. В BoK-репозитории ты можешь:
- Запустить `/study-concept <slug>` для концептов, по которым ошибся
- Запустить `/solve-problem` и применить концепты на своём кейсе — это лучший способ закрепить
