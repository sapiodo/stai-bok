# Глоссарий

Термины и переводы, используемые в BoK. Английский оригинал — для соответствия источникам.

## Системное мышление — базовые понятия

| Русский | English | Определение |
|---|---|---|
| Системное мышление | Systems Thinking | Способ анализа, при котором фокус — на структуре и взаимодействии частей, а не только на самих частях |
| Ментальная модель | Mental Model | Внутреннее представление о том, как устроен мир / организация / процесс |
| Нежелательное явление (НЯ) | Undesirable Effect (UDE) | Конкретное наблюдаемое проявление проблемы |
| Корневая причина | Root Cause | Глубинная причина повторяющегося НЯ |
| Граница влияния | Sphere of Influence | Точка, до которой ты можешь воздействовать; дальше — внешний контекст |
| Парадокс рычага | Leverage Paradox | Сильнее рычаг → сложнее его использовать |

## Cynefin — домены

| Русский | English | Природа задачи |
|---|---|---|
| Ясный | Clear (ex-Simple, ex-Obvious) | Известная причина-следствие, best practice работает |
| Запутанный | Complicated | Причина-следствие выявляется анализом экспертов |
| Сложный | Complex | Причина-следствие видна только в ретроспективе |
| Хаотичный | Chaotic | Нет видимых причинно-следственных связей, нужно действие |
| Беспорядок | Disorder | Неясно, в каком домене находишься |

## Iceberg Model — уровни

| Русский | English | Что описывает |
|---|---|---|
| События | Events | Конкретные факты, инциденты |
| Паттерны | Patterns | Повторяющиеся закономерности |

## Causal Loop Diagrams (CLD)

| Русский | English | Обозначение |
|---|---|---|
| Усиливающая петля | Reinforcing Loop (R) | Чётное число `(−)` стрелок |
| Балансирующая петля | Balancing Loop (B) | Нечётное число `(−)` стрелок |
| Однонаправленное влияние | Same-direction Link | `(+)` |
| Обратное влияние | Opposite-direction Link | `(−)` |
| Задержка | Delay | `→\|\|` |

## Системные архетипы

| Русский | English | Краткая характеристика |
|---|---|---|
| Пределы роста | Limits to Growth | Рост упирается в ограничение, замедляется |
| Перекладывание бремени | Shifting the Burden | Зависимость от quick fix, фундаментальное решение атрофируется |

## Адаптации Master Strategy

Термины и подходы, представляющие собой авторскую адаптацию методологии:

- **Мультистейкхолдерный Iceberg** — структуры общие, ментальные модели РАЗНЫЕ у разных стейкхолдеров
- **Две проблемы для продуктовой работы** — пользователя + команды
- **Три проблемных архетипа** (Собиратель/Охотник/Координатор) — адаптация Cynefin к проектной работе
- **ОНМС** — критерии стратегических ставок
- **Pipeline Iceberg → CLD → Leverage Point** — обязательная последовательность диагностики при смешанной корневой причине
- **«Нет субъекта — нет проблемы»** (Федин, цитируется в курсе) — принцип субъектности проблемы
