# Как использовать BoK

Это не учебник, который читают линейно. Это **база знаний + два навыка**, которые подстраиваются под твою задачу. Ниже — короткий гид: какой режим выбрать в зависимости от того, зачем ты пришёл.

## Три причины открыть BoK

### 1. У тебя есть конкретная проблема

> «У меня в команде проблема X / у моего продукта проблема Y / в моей жизни ситуация Z».

**Что делать:**
1. Открой Claude Code в корне репозитория
2. Запусти `/solve-problem`
3. AI спросит про систему, нежелательные явления и стейкхолдеров
4. Пройди 4 фазы pipeline с диалоговыми точками (Д1-Д4)
5. На выходе — портфель гипотез + план экспериментов + (опц.) сопровождение

**Сколько времени:** 1-3 часа на полный pipeline. Можно прервать после любой фазы и вернуться.

**Артефакт:** пояснительная записка (ПЗ) с полным разбором. Подходит для совместной работы с командой / преподавателем / ментором.

### 2. Ты хочешь освоить методологию

> «Хочу разобраться в системном мышлении. С чего начать?»

**Линейный путь (если есть время):**
1. Прочти лекционные конспекты `lessons/L1` → `lessons/L7` по порядку
2. После каждого конспекта — пройди соответствующий квиз из `self-tests/`
3. По концептам, в которых не уверен → `/study-concept <slug>`
4. В конце — попробуй `/solve-problem` на своём кейсе

**Concept-driven путь (если время ограничено):**
1. Открой `concepts/_index.md`
2. Выбери 3-5 ключевых концептов в зависимости от твоей роли:
   - **Продакт-менеджер:** `problem-formulation`, `iceberg-model`, `leverage-points`, `hypothesis-portfolio`, `experiment-design`
   - **Тимлид / руководитель:** `cynefin`, `system-archetypes`, `stakeholder-map`, `creative-tension`
   - **Стратег / основатель:** `creative-tension`, `scenario-thinking`, `strategic-bets`, `leverage-points`
   - **Аналитик / консультант:** `iceberg-model`, `causal-loop-diagrams`, `system-archetypes`, `evaporating-cloud`
3. По каждому — `/study-concept <slug>` в режиме `deep-study`

### 3. Тебе нужна справка

> «Я уже знаю Iceberg. Просто хочу освежить шаги построения CLD.»

**Что делать:**
- Просто открой нужную карточку: `concepts/05-causal-loop-diagrams.md`
- Слой 3 (Применение) — алгоритм и чек-лист
- Если нужно быстро освежить «по верхам» — `/study-concept quick causal-loop-diagrams` (3 слоя: знакомство → принципы → границы и связи)

## Как работают skills

### `/solve-problem` — orchestration

4 фазы с обязательной остановкой на каждой:

```
Формулирование → Д1 → Диагностика → Д2 → Решение → Д3 → Реализация → Д4
```

На Д-точках можно: подтвердить, скорректировать, прервать на изучение нужного концепта (через `/study-concept`), вернуться к предыдущей фазе.

### `/study-concept`

Прохождение одной концепции по 5 слоям Learning Object:

```
Знакомство (С1) → Понимание (С2) → Применение (С3) → Рефлексия (С4) → Интеграция
```

Режимы:
- `/study-concept iceberg-model` — полный deep-study
- `/study-concept quick cynefin` — слои 1, 2, 5 (короткое освежение)
- `/study-concept compare iceberg-model causal-loop-diagrams` — два концепта рядом

## Артефакты твоей работы

Сессионные артефакты (ПЗ, заметки по применению) **не клади в этот репо** — он в `.gitignore`. Используй личную рабочую папку.

Если хочешь поделиться результатом — например, с командой, преподавателем или ментором — экспортируй ПЗ в Google Doc / PDF / общий канал.

## Что делать, если что-то непонятно

1. Перечитай конспект соответствующего занятия (`lessons/`)
2. Запусти `/study-concept <slug>` для проблемного концепта
3. Если проблема в применении — запусти `/solve-problem` на маленьком ясном примере, чтобы прочувствовать pipeline
4. Если нашёл ошибку в материалах — GitHub Issues / PR

## Что НЕ ждать от BoK

- **Это не сертификация.** Прохождение квизов не даёт diplom-а.
- **Это не консультация.** AI работает по канону, не заменяет живого ментора с опытом в твоей предметке.
- **Это не «волшебная таблетка».** Системное мышление меняет оптику, но решения принимаешь ты, и ответственность за них — твоя.
